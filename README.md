# Book Collection App

This project is a web application to manage your book collection, developed with React and Vite.

## Demo
Netlify demo here:  
[https://super-taiyaki-49a287.netlify.app/](https://super-taiyaki-49a287.netlify.app/)

## Prerequisites

- Node.js (v20 or higher recommended)
- npm

## Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/your-username/your-repo.git
   cd 11_client-side_final-project_frontend
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

## Development usage

To start the development server:

```sh
npm run dev
```

The app will be available at [http://localhost:5173](http://localhost:5173) (or the port shown in the terminal).

## Available scripts

- `npm run dev` — Starts the development server.
- `npm run build` — Builds the production version in the `dist` folder.
- `npm run preview` — Serves the production build locally.
- `npm run lint` — Runs ESLint to check the code.
- `npm run test` — Runs tests with Vitest.

## Environment variables

You can set the API URL in the `.env` file:

```
VITE_API_URL = "http://localhost:3000/books"
```

## Testing

To run the tests:

```sh
npm run test
```
